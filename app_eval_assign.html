2단계: 교사 명단 업로드

엑셀 컬럼 작성 안내
📌 이름 — 교사 이름
📌 과목 — 담당 과목
📌 담당학급 — 담임반 (예: 1-2) 없으면 빈칸
📌 수업시수 — 주당 시수 (많을수록 감독 많이 배정)
📌 누적횟수 — 이전 학기까지 감독 횟수
📌 배정역할 — 정감독만 / 부감독만 / 복도만 / 빈칸=모두 가능
📌 수업참여횟수 — 시험기간 중 다른 학년 수업 들어간 횟수
→ 감독 횟수로 간주해 배정 비율에 자동 반영
⚠️ 배정불가 컬럼 작성법
• 화 → 화요일 전체 배정불가
• 수1,수2 → 수요일 1교시·2교시만 배정불가
• 화,수1,수2 → 화요일 전체 + 수요일 1·2교시 배정불가
• 1교시 → 요일 상관없이 매주 1교시 배정불가
쉼표로 여러 조건 나열, 교시는 숫자만도 가능
💡 수업시수·누적횟수 안내
• 수업시수·누적횟수를 0으로 입력하면 모든 교사가 동등하게 균등 배정됩니다
• 시수가 높을수록 감독 배정 횟수가 비례하여 많아집니다

여기를 클릭하여 작성된 교사 명단 엑셀을 업로드하세요

💡 배정불가상세 컬럼으로 특정 요일의 특정 교시만 제외 가능
예: 수 1,2 → 수요일 1·2교시 불가 / 수 1,2 / 화 3 → 수요일 1·2교시 + 화요일 3교시 불가
